Laptop Monitor

Your second screen, in a browser.

Start Laptop Monitor on the Windows PC and type the six-character code it shows. The virtual display then fills this screen.

A new code appears every two minutes. A connection that is already up keeps running.

Advanced

The signaling server only introduces the two computers; video travels directly between them. The address is remembered on this device.

Sender test (for developers)

Streams from this browser instead of the native host, to test pairing and WebRTC. It publishes a one-off code for two minutes.

Video goes straight from the PC to this laptop over WebRTC. Nothing passes through a server.
